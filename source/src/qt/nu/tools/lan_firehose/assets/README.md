## LAN Firehose Throughput Test artwork

`firehose_icon.svg` was created for the Defcoin Core Nu LAN Firehose Throughput
Test app. It is original project artwork based on the requested red hydrant,
water spray, and binary data motif.

The app icon PNG and `.icns` files are generated from this SVG during local
packaging and may be redistributed with Defcoin Core Nu builds under the same
license terms as the surrounding Defcoin Core Nu project.

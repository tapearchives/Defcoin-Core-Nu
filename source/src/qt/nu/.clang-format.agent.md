# .clang-format Agent Notes

## Purpose

Defines the local clang-format profile for Nu-owned C, C++, Objective-C, and Objective-C++ files under `source/src/qt/nu`.

## Nu Divergence

- Inherits the spirit of the Litecoin/Core `source/src/.clang-format` style but tightens readability for Nu app code.
- Uses a 120-column limit and disables compressed one-line functions, `if` statements, blocks, loops, and case labels.
- Keeps 4-space indentation, pointer-left style, and Core-compatible brace wrapping.

## Do Not Break

- This file must not affect backend/Core files outside `source/src/qt/nu`.
- Do not run broad formatting over upstream-derived Core files as part of Nu UI style changes.
- Do not use this as a QML formatter; QML layout remains governed by local QML conventions and visual review.

## Verification

- `git diff --check`
- `/usr/bin/xcrun clang-format -style=file --dump-config` from this folder should parse successfully on Tahoe/Xcode.

# Defcoin Core Nu 26.6.1b Release Notes

Defcoin Core Nu `26.6.1b` is a small diagnostics polish build over `26.6.1a`.
The inherited Core client build number is unchanged.

## Diagnostics

  Name`: LAN workstation names are left-aligned, while non-LAN seed and DNS
  source values remain right-aligned.

# Defcoin Core Nu 26.6.2g Release Notes

Defcoin Core Nu `26.6.2g` is a Droid Trails chart usability update over
`26.6.2f`.

## Droid Trails Chart

- The chart popout is constrained for a 1920x1080 screen so the chart, detail
  text, DEF CON window table, and footnote remain visible without scrolling.
- Chart legends now show larger, easier-to-read totals for candidate outputs,
  0.1337 swarm outputs, and 0.01 action outputs.
- Hovering a DEF CON bar shows block range, dates, candidate DFC, transaction
  counts, address counts, and exact fractional-signal counts.
- Clicking a DEF CON bar zooms into that window and redraws the chart as a
  detailed count profile.
- The All windows control returns the chart to the full DEF CON comparison.
- Double-clicking a row in the Droid Trails window table opens the same detail
  chart for that row.

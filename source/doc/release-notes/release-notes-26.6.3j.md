# Defcoin Core Nu 26.6.3j Release Notes

Defcoin Core Nu `26.6.3j` is a Nu Explore UI polish update over
`26.6.3i`.

## Nu Explore UI Polish

- Moves Network Pulse chart and sampling controls into the section header so
  the chart and history table get more usable vertical space.
- Adds a direct Network Pulse status-copy action while preserving selectable
  status text.
- Gives the embedded and pop-out Network Pulse tables stable minimum heights
  for easier 1080p use.
- Keeps the pop-out control layout consistent with the embedded view, including
  hover/click chart behavior and the same Refresh control placement.

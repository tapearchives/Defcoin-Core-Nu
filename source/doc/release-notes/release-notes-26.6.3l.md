# Defcoin Core Nu 26.6.3l Release Notes

Defcoin Core Nu `26.6.3l` is a Nu Explore UI polish update over
`26.6.3k`.

## Nu Explore UI Polish

- Treats a loaded Droid Trails cache as a healthy mast state, so cached
  Coindroids analysis no longer appears as an inactive grey indicator.
- Adds a compact Fit action to Movement Map controls in both the embedded view
  and pop-out window.
- Fit clears dragged node positions and reruns the graph layout without
  changing the selected threshold, sort mode, node count, or node scale.

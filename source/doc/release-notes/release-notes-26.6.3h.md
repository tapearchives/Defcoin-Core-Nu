# Defcoin Core Nu 26.6.3h Release Notes

Defcoin Core Nu `26.6.3h` is a Nu Explore Coindroids readability update over
`26.6.3g`.

## Nu Explore Droid Trails

- Removes hard height caps from Coindroids header, status, and pop-out
  narrative text so wrapped text remains visible and selectable.
- Keeps the Droid Trails, DC25 Payout Hunt, and DC25 Attack Chain bodies
  scroll-safe when long notes, charts, and tables exceed the current window
  height.
- Adds full-value hover text for compact metric rows and truncated data-table
  headers/cells so dense Coindroids tables remain readable without widening
  every column.

## Relationship Graph Carryover

- Preserves the `26.6.3g` Coindroids table-scoped Chart Relationships actions,
  accepted Olo eighth-lead treatment, draggable relationship graph nodes, and
  indexed balance/received sizing.
